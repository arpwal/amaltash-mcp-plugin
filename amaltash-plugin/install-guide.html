Hosted

Amaltash plugin for Claude Code

Install & test guide — the plugin connects to the hosted MCP server at https://mcp.amaltash.com. Nothing runs locally — no Python, no binary.

How auth works. The hosted server authenticates each request with your personal amat_… token, sent as an Authorization: Bearer header. You create the token once in your Amaltash dashboard and expose it to Claude as an environment variable. Revoke or rotate it any time from the same screen.

1Prerequisites

  • Claude Code (CLI, desktop, or IDE extension).
  • A signed-in Amaltash account (to create a connector token).

2Create a connector token

In your Amaltash dashboard, open Settings → Security → Claude connector and click Create token. Copy it immediately — it is shown once and looks like amat_….

Expose it to Claude as an environment variable (add it to your shell profile to persist across restarts):

# macOS / Linux — add to ~/.zshrc or ~/.bashrc to persist
export AMALTASH_AGENT_TOKEN="amat_…"

The bundled .mcp.json reads ${AMALTASH_AGENT_TOKEN} and sends it as the Bearer header — no other configuration is needed.

3Add the plugin marketplace & install

Run these inside Claude Code:

# Register the marketplace straight from GitHub
/plugin marketplace add arpwal/amaltash-mcp-plugin

# Install the plugin (plugin@marketplace)
/plugin install amaltash@amaltash

Restart Claude Code, then confirm the server is connected:

/mcp

You should see amaltash connected with its tool list, and the amaltash-trading skill available.

Token not set? Claude Code expands ${AMALTASH_AGENT_TOKEN} at launch. If it's empty, the server replies with a clear "create a token" message — set the variable (step 2) and restart Claude Code.

4Try it

“Show my Amaltash account, check my onboarding status, then create a momentum strategy on SPY and backtest it.”

Claude will read your account → connection_status → create_strategy → backtest_strategy (returns metrics + an equity curve).
